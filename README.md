# Distributed COVID-19 Big Data Analytics Platform

A distributed Big Data analytics platform for processing historical
COVID-19 data using Hadoop HDFS, Apache Spark and MongoDB.

## Project Overview

This project processes Google COVID-19 Open Data using a distributed
3-node Hadoop cluster consisting of one Master node and two Worker nodes.

The system uses:

- Hadoop HDFS for distributed storage
- Apache Spark / PySpark for distributed processing
- MongoDB for NoSQL storage and querying
- Python for application development
- Jupyter Notebook for exploration and visualization
- Docker for reproducible cluster deployment
- GitHub for version control and collaboration
